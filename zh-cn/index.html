作品

Idol Showdown

一款免费的 hololive 同人格斗游戏，采用回滚网络代码。下载量超过120万次，Steam 评分9/10。

我在 Besto Games 担任系统程序员期间，基于 SDL 实现了输入处理，完成了 Wwise 音频集成，参与了 UI 开发，在 Unity Editor 中编写了调试和跟踪工具，还做了一个 bug 追踪器，把策划提交的报告直接送进我们的 CI/CD 流水线。

年份
2020–2025年
技术栈
Unity, C#, C++, SDL, Wwise

BestoNet

面向 Unity 的开源回滚网络代码，用 C# 为 Idol Showdown 编写。它取代了游戏原有的 GGPO 集成，以消除中继延迟和多帧回滚 bug。

我负责推测式帧保存、输入预测、保持双方时钟同步，以及能应对丢包和乱序的7帧输入缓冲区。

开源时间
2024
技术栈
C#, Unity, Steamworks
